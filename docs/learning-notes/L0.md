# L0 学习笔记：仓库骨架与模块边界

## 本层做了什么

只让 Python 找得到包，并冻结「数据不写 C 盘用户主目录」。没有 Agent、没有工具、没有记忆读写。

## 应重点理解的代码 / 概念

1. **入口与领域包分开**  
   `main.py` 只负责启动（L0 甚至只打印一句话）。领域逻辑进 `agent` / `tool` / `memory`，编排进 `core`，人机交互进 `ui`。这样 L2 接模型时不必先长出一套 REPL 框架。

2. **三个独立目录不是风格问题**  
   - `agent`：何时向模型发请求、如何拼 instructions、如何跑子 Agent。  
   - `tool`：模型能调用的副作用（磁盘、Shell、MCP）。  
   - `memory`：跨会话笔记与检索。  
   参考实现里 tools 挂在 `agent/tools/`，hooks 又 import UI，形成环。本项目从 L0 就把三包拆开，跨包只许依赖 `interfaces/`（L1 才写协议）。

3. **依赖只能向外长**  

   ```text
   ui / examples
     → core
       → agent | tool | memory
         → safety | session | llm | config
           → interfaces | utils
   ```

   `agent` 不得 import `ui`；`memory` 不得 import 具体 `tool.file`。

4. **F006 为何在 L0 冻结**  
   参考项目 `Path.home() / ".my-claude-code"` 在 Windows 落在 C 盘。路径一旦写进 store / permissions / skills 三处，后面再改会牵动硬卡口。L0 只把约定写进 README 和词汇表；L2 实现解析函数；L4 才 mkdir。
